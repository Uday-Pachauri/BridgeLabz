Responsive CSS Cheat Sheet

Learn Important CSS Concepts

Filters

CSS filters change the appearance of images.

filter: grayscale(100%);

Media Queries

Media queries apply styles according to screen size.

@media (max-width: 700px)

Responsive Design

Responsive design makes websites fit different devices.

width: 100%;

Typography

Typography controls the size and appearance of text.

font-size: clamp(1rem, 4vw, 2rem);

Flexbox

Flexbox aligns and arranges elements in a layout.

display: flex;

CSS Grid

Grid creates rows and columns for page layouts.

display: grid;
