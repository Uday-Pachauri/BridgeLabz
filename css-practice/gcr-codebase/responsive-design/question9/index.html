Responsive Design Principles

Learn the three important principles of responsive design.

Fluid Layouts

Fluid layouts adjust the width of elements according to the available screen size.

width: 100%;

Flexible Media

Flexible media allows images and videos to resize according to their containers.

max-width: 100%;

Breakpoints

Breakpoints change the layout when the screen reaches a particular width.

@media (max-width: 600px)
